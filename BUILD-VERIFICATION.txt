STELLAR CARTOGRAPHY PWA — REVISION 23.4.1 STABLE RUNTIME

ROOT CAUSE FIXED
The previous v23.4 deployment appended the v23, v23.3 and v23.4 feature scripts outside the primary campaign IIFE. Those scripts referenced private lexical bindings from the core runtime, producing immediate browser ReferenceErrors including CAMPAIGN_TECH_NAMES, campaignFoundSettlement and CAMPAIGN_BUILDING_CHAINS. The UI could therefore reach the title/setup screen while the later campaign systems never initialised correctly.

FIX
- Consolidated the v23, v23.3 and v23.4 feature layers into the primary campaign lexical scope.
- Preserved every feature wrapper and compatibility layer; feature logic was not stripped.
- Removed controllerchange / forced reload behaviour from the title-screen runtime.
- Reduced service-worker registration to one stable registration path.
- Kept sw-v23-4.js as a compatibility alias so an existing v23.4 Home Screen installation can update its old worker registration.
- Service worker is network-first for navigations and falls back to the cached v23.4.1 application shell offline.
- No external JS/CSS/CDN dependencies are required by index.html.
