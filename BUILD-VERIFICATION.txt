FLEET MOVEMENT
- Direct translations can be ordered entirely from the Fleets tab.
- Waypoint mode supports manually planned itineraries.
- Auto-Route creates intermediate waypoints for long inter-system travel when useful.
- Up to 24 waypoints may be stored in one confirmed journey.
- Full-route Supply + 1 Command are reserved when the route is confirmed.
- Subsequent route legs begin automatically when each waypoint is reached.
- Existing per-fleet strategic action cap is retained; a confirmed multi-journey consumes one fleet action when ordered.
- Existing map-click plot-and-confirm movement remains available as an alternate workflow.

FLEET DEVELOPMENT / FLEET-COLONY
- Tier I: Sustained Logistics Refit.
- Tier II: Habitat & Civilian Decks.
- Tier III: Mobile Colony Core; fleet is simultaneously a fleet and settlement.
- Tier IV: Migratory Enclave; mobile expedition/survey capacity begins.
- Tier V: Fleet-City; stronger economy, mobilisation and expedition capacity.
- Mobile colonies contribute income, defence, diplomatic power, mobilisation and resource/expedition access where applicable.
- Mobile colonies appear in both Fleets and Colonies interfaces.
- Faction can adopt Fleet-Colony polity after obtaining a Tier III+ mobile settlement.
- AI can develop suitable fleets toward mobile colonies.
