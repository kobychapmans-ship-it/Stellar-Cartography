REFERENCE NOTE
The canonical-location feature is modelled primarily on the Jambonium interactive 30k/40k map. The source itself distinguishes location placement confidence, so Cartographica anchors names to generated theatre nodes rather than presenting its procedural LY coordinates as exact setting coordinates.

BROWSER LIMITATION
The container browser environment is not reliable for a full local-file/localhost click-through. This release therefore uses syntax validation, source-path auditing and deterministic configuration/state checks; no unsupported interactive-browser claim is made.
