Source Fidelity Notes
The generator follows the uploaded guide's sequence: system type → star class/size → decimal → companions → orbit count/zones → orbital contents → captured bodies → satellites → detailed planet generation → minerals → optional Imperial classification. Some printed tables contain overlaps, gaps, or formula conflicts; Practical Errata is an explicit software interpretation, while Book Literal surfaces them rather than hiding them.
Sub-sector placement and the interstellar “dead-space” layer are a setting expansion beyond the uploaded star-system book. Every individual system inside a generated sub-sector still uses the book-derived stellar and planetary procedure. Setting-specific void entries are marked separately as Cartographica / lore overlay data.
Fan-made utility. Fully self-contained: no network connection, remote libraries, fonts, images, or APIs are required for generation or 3D maps.
