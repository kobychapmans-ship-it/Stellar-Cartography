SAVE STORAGE TEST NOTE
The automated Chromium harness loads the application into an opaque document origin, where Chromium denies persistent IndexedDB/localStorage by security policy. The Save/Resume test therefore exercised v30's designed embedded-snapshot fallback. IndexedDB store/open/load code parsed and loaded without causing application errors, but a persistent-origin IndexedDB transaction cannot be truthfully claimed from this harness. The fallback exists specifically so campaign saves continue functioning if persistent browser storage is unavailable.
