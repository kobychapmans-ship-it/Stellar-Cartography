# Stellar Cartographica v29.1 — Horus Heresy Mission Theatre Audit

## Scope
v29.1 converts the v29.0 Horus Heresy mission board into mission-instance campaigns. Only one mission may be active at once. Active missions can be completed/failed or saved; saving snapshots the full local theatre and reopens the current 90-day mission board. Saved theatres can later be resumed without regeneration.

## Mission theatre generation
Every chronology event receives a deterministic theatre profile:
- System scale for individual battles, worlds and compact clusters.
- Subsector scale for prolonged multi-system crusades/campaigns.
- Sector scale for galaxy-strategic theatres such as Beta-Garmon, the Solar War and War Within the Webway.

Coverage test over the imported chronology:
- 41 90-day segments
- 871 event appearances
- 0 events without a valid theatre profile
- 574 system-scale instances
- 149 subsector-scale instances
- 148 sector-scale instances

The default generator derives location, participant sides, strategic strength and deterministic map seed from the chronology event. Authored Order-of-Battle overrides can replace these estimates mission-by-mission without changing the framework.

## Signus authored calibration
Signus is the first high-fidelity authored theatre benchmark. It is generated as a trinary Signus Cluster and seeds:
- Blood Angels Legion — strategic muster 120,000; canonical fleet annotation ~382 vessels
- Armada Imperialis & Narthex Cull Regiments — strategic muster 18,000
- Legio Cybernetica Support — strategic muster 9,000
- Ka’Bandha & Kyriss Daemonic Hordes — strategic muster 145,000 (scenario-scale estimate; daemon total is not presented as a canonical exact count)
- Word Bearers Detachment — strategic muster 3,420
- Task Force Ygethddon — strategic muster 6,500 (scenario-scale estimate)
- Additional player faction when selected — small intervention force based on mission funding

The public lore calibration records the Signus Cluster as seven worlds and fifteen moons and gives the Blood Angels force as roughly 120,000 legionaries with 382 Legion fleet voidships. The theatre framework records this canonical metadata while the procedural stellar-body layout remains generated by Cartographica.

## Side-specific objectives
The Overview tab now displays the active mission and its objectives. Signus includes authored objective sets for:
- Blood Angels / historical loyalist side
- Daemonic / historical traitor side
- Additional-faction intervention

Other missions use event-derived objectives and invert/translate them for the chosen historical side until authored mission-specific objective packs are added.

## Existing-system regression protection
The v28.3 authoritative fleet-transit code remains present. v29.1 does not replace the End Turn fleet-transit pipeline.

## Known content-depth limitation
The framework can generate a valid mission theatre for every imported event, but only selected events currently have authored exact/near-exact Order-of-Battle overrides. For less documented missions the strategic points values are deterministic gameplay estimates, not claimed canonical headcounts. Horus Heresy Black Books 1–9 can be used in a later content pass to replace those estimates with much richer named formations, vessels, commanders, deployments and mission-specific settlements.
